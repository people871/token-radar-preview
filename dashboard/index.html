    Set aside by the house rule — — protocols

    These protocols are in the snapshot but are not ranked, because the house rule sets them aside before any scoring: centralised exchanges; versioned names (a trailing v2, v3, …); wrapped, staked or staking names; the six excluded categories (CEX, Centralized Exchange, Derivatives, Options, Prediction Market, Gaming); and names that start with an exchange name. The rule is applied to the name and category only — never to a protocol’s size — so a large protocol can still be set aside, and a small one can still rank. Nothing on this list is scored, given an implied value, or given a farm plan.

    Method and backtest

    How the size curve is fitted

    Only tokens that already trade are used to fit the curve, and only pre-token protocols are scored with it. On the snapshot’s traded tokens we fit a log-log ordinary least squares line: log10(market cap) = intercept + slope × log10(TVL / $100M). The fitted line is the size curve: a protocol’s TVL alone, before any family offset, maps to a size value. The four fitted numbers are printed in the “How a launch is priced” panel above and are read from the bundled data, not typed here.

    Family, growth and seasoning

    Three multipliers adjust the size value. Family is the protocol’s category mean residual from the fitted line, shrunk toward 1 when the category has few traded tokens — a category whose traded tokens sit above the line lifts its pre-token members, and one below the line pulls them down. Growth comes from the 7-day TVL change: fast-growing protocols are worth more than a flat protocol at the same TVL. Seasoning comes from age with no token: a protocol that has run a long time without launching is discounted against one that is fresh, because the longer the wait, the less a launch is priced in. Implied value = size value × family × growth × seasoning. The P10–P90 range around it is the blind residual range from the backtest below, so the band is earned from prediction errors, not assumed.

    How the blind backtests work

    Leave-one-out (LOO): each traded token is held out in turn, the curve is refit without it, and the held-out token is predicted blind. The median blind error and the share of predictions within 3× of the true market cap are reported against the same test for a flat baseline — one median market-cap/TVL multiple applied to every token. Time split: the curve is fitted only on tokens listed before 2024 and tested on tokens listed later, so the test is genuinely future data. Bands: the share of traded tokens whose true market cap falls inside the blind 50% and 80% bands. A fitted curve that only beats the flat baseline on the data it was fitted on proves nothing; the numbers in the table are all out-of-sample.

    How a farm verdict is computed

    Every verdict is priced at the same fixed terms: $1,000 of capital and a 10% airdrop share of the implied value, pro-rata to TVL. The slice is 10% of the implied value scaled to $1,000 of capital. Fees are five transactions at the chain’s typical gas. T-bill forgone is the 4% annual return the $1,000 would have earned parked in a T-bill for the hold days. Net = slice − fees − T-bill forgone. FARM if net ≥ $1, THIN if −$10 ≤ net < $1, SKIP if net < −$10. The verdict is therefore a statement about the economics at $1,000, not about whether the protocol is good: a large implied value can still be SKIP if the slice it buys at $1,000 does not cover the gas and the forgone T-bill return. The farm plan lists the seven concrete steps, each with its own cost and time, and the scenario table shows the net if the token drops 5%, 10% or 20% at $1.0K, $10.0K and $100K of capital.

    What is not done

    No protocol name is special-cased anywhere: one function scores every row from TVL, 7-day change, age, category and chains. Traded tokens are never given a model value and pre-token protocols are never given a market cap. Nothing on this page is fetched at view time — the snapshot, the fitted model and the board are bundled with the page, and the page works with no network.
